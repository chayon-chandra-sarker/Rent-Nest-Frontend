# API Integration

| Frontend Component | Method | Backend Endpoint                | Purpose                        |
| ------------------ | ------ | ------------------------------- | ------------------------------ |
| Login Form         | POST   | `/api/auth/login`               | User login                     |
| Register Form      | POST   | `/api/auth/register`            | User registration              |
| Navbar / Auth      | GET    | `/api/auth/me`                  | Get logged-in user             |
